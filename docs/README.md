## دامنه پیشنهادی نسخه ساده

- یک نقشه کوچک سه‌بعدی با دوربین زاویه‌دار، شش بازمانده، آتش، دو چادر، چهار منبع اصلی و چند نقطه کار. شکل زمین و رنگ‌ها از مرجع تصویری الهام می‌گیرند و دارایی‌های بازی اختصاصی خواهند بود.
- شغل‌های اولیه، مصرف غذا و آب، یک سازنده هم‌زمان، مزرعه قابل ساخت، نقش کشاورز، چادر سوم و رشد قابل مشاهده کمپ. برای فضای ساخت، چند مسیر اصلی رزرو می‌شوند تا آدم‌ها به منابع برسند.
- یک جایگاه ذخیره، تولید آفلاین با سقف پیشنهادی هشت ساعت و گزارش تولید و مصرف. منطق اقتصاد در هر دو حالت از یک مسیر اجرا می‌شود.
- یک کارگاه، یک شغل بازیافت، یک پژوهش اثرگذار، یک ارتقای قابل مشاهده، یک راهنمای کوتاه و پذیرش نفر هفتم. انبار مستقل، ساختمان‌های تولیدی اضافه، درخت پژوهش چندشاخه و محتوای فصل کامل برای تصمیم بعدی پیشنهاد می‌شوند. این کاهش‌ها با جدول کامل GDD تفاوت دارند و قبل از تثبیت دامنه بررسی می‌شوند.
- Godot 4 با GDScript پیشنهاد پایه است. Windows برای اجرای اولیه و تکرار سریع آزمون‌ها در اولویت است. Android همچنان مقصد خروجی است و آمادگی SDK و تست لمس جداگانه ثبت می‌شود. وضعیت iOS برای نسخه‌های بعدی باز می‌ماند.

## تصمیم‌های پیشنهادی برای ساده ماندن بازی

| تصمیم | اثر قابل مشاهده و آزمون |
| --- | --- |
| تولید بر پایه شغل معتبر | نرخ منابع با تخصیص تغییر می‌کند و شخصیت بلافاصله مسیر جدید می‌گیرد. زمان سفر در نسخه ساده یک هزینه اقتصادی جداگانه ایجاد نمی‌کند. تایمر ساخت پس از رسیدن سازنده آغاز می‌شود. |
| یک ساعت برای اقتصاد فعال و آفلاین | گام یک‌ثانیه‌ای نقطه شروع است. زمان هشت‌ساعته و هزینه بارگذاری روی سخت‌افزار واقعی اندازه‌گیری می‌شوند. هر بهینه‌سازی باید آزمون برابری نتایج را پاس کند. |
| کمبود قابل حل | غذا و آب منفی نمی‌شوند. هشدار راه‌حل مشخص دارد و تخصیص نفر دوم به منبع کمبود باید واقعاً وضعیت را بهبود دهد. |
| یک مسیر یادگیری | تغییر شغل، ساخت مزرعه، ساخت کارگاه و پذیرش نفر هفتم هم ترتیب راهنمای بازی‌اند و هم سناریوی آزمون کامل. |

## مسیر GitHub پس از این بررسی

مخزن عمومی `Hamedhanifeh/the-last-civilization` هنگام اتصال، خالی بود. پیشنهاد برای ادامه یک شاخه `codex/` برای هر گام و یک PR پس از آزمون است. سورس، صحنه‌ها، داده‌ها، منابع مجاز، مستندات و آزمون‌ها در GitHub ثبت می‌شوند. فایل‌های اجرایی تحویل را می‌توان کنار نسخه در Releases گذاشت. پرونده وبینار، کش و فایل‌های محلی محرمانه خارج از بسته بازی‌اند.
